WhatCable follows semantic versioning. Releases are published on the [GitHub Releases page](https://github.com/darrylmorley/whatcable/releases).

No `CHANGELOG.md` file is present in the repository. The full release history, including per-version notes, is maintained directly on GitHub Releases.

<Note>
  Each release on GitHub includes signed release notes and a SHA-verified zip download. You can verify the download integrity using the SHA checksum published alongside each release asset.
</Note>

To view the complete release history, visit:
