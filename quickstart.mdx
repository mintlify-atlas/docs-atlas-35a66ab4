---

WhatCable is ready to use the moment it launches. This guide walks you from a fresh install to reading a live port diagnostic in the menu bar and running your first CLI command. The whole thing takes under a minute.

<Steps>
  <Step title="Install WhatCable">
    Install via Homebrew (recommended) or download the signed zip from the GitHub Releases page. See the [installation guide](/installation) for full details.

    ```bash
    brew tap darrylmorley/whatcable
    brew install --cask whatcable
    ```
  </Step>
  <Step title="Open the menu bar popover">
    Launch `WhatCable.app` from `/Applications`. A small icon appears in your menu bar. Click it to open the popover — you will see one card for each USB-C port on your Mac, even ports with nothing connected.
  </Step>
  <Step title="Plug in a cable">
    Connect any USB-C cable. The port card updates in real time without any manual refresh. The headline line switches from *Nothing connected* to a plain-English verdict such as *Thunderbolt / USB4*, *USB device*, or *Charging only*. Below the headline, bullet points detail the active transports, e-marker status, and negotiated power profile.
  </Step>
  <Step title="Read the charging diagnostic">
    If you connected a charger, a banner appears beneath the headline identifying the charging bottleneck. It tells you whether the cable, the charger, or the Mac itself is the limiting factor, and what wattage is currently being negotiated. If everything is matched, it confirms that charging is running at full speed.
  </Step>
  <Step title="Try the CLI">
    Open a terminal and run `whatcable` for a human-readable summary of every port. Add flags to change the output format or behaviour:

    ```bash
    whatcable            # human-readable summary of every port
    whatcable --json     # structured JSON output, pipe into jq
    whatcable --watch    # stream live updates as cables connect and disconnect (Ctrl+C to exit)
    ```
  </Step>
</Steps>

## CLI flag reference

| Flag | Description |
|---|---|
| `--watch` | Continuously monitor for changes; streams updates until you press Ctrl+C |
| `--json` | Output structured JSON instead of human-readable text |
| `--raw` | Include the underlying IOKit properties for each port alongside the summary |
| `--version` | Print the version string and exit |
| `-h`, `--help` | Show usage information and exit |

<Tip>
In the menu bar app, hold ⌥ (Option) and click the menu bar icon to toggle the raw IOKit property view for every port. You can also enable it permanently in Settings. This is useful for debugging or cross-referencing what WhatCable reports against `ioreg` output.
</Tip>
